# results/ — what each file is

| File | Meaning |
|---|---|
| `out_A.csv` | Condition A, rules only (Tier 0, no model). Deterministic. |
| `out_<1b\|3b\|7b>.csv` | Local model, **prompt v1** (the pre-registered prompt), 24 test scenarios × reps |
| `out_<1b\|3b\|7b>_v2.csv` | Same models, **prompt v2** (explicit decision procedure) — tuned on the dev set only |
| `dev_<model>_<v1\|v2>.csv` | 12 held-out **dev** scenarios (`../scenarios_dev.json`), 3 reps — used to choose v2; never mix with test |
| `tables.md`, `summary.json`, `failures.md`, `fig_*.png` | Generated by `make_tables.py` from the CSVs above |
| `v1_seedfixed_bug/` | An early 1B run where every repetition used the same sampling seed, so the 5 reps were identical. Kept only for transparency; **not** used in any table. Fixed: seed = repetition index. |

Method notes for the paper: temperature 0.2; seed = rep index (0…4); JSON mode on; one warm-up call excluded from latency;
prompt v2 was written after seeing v1's dominant failure category on the test set (over-notification of routine events) and
evaluated on the dev set before the test set; no test-scenario text appears in either prompt's examples
(v1's single few-shot example resembles test scenario H-C1 — disclose this).
